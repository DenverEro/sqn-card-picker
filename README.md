# Card Picker (Side Quest Nexus)

Search Magic: The Gathering cards with Scryfall syntax, see current prices,
click + to add cards, and copy the list into Moxfield, Archidekt or any deck
builder's import box.

Single static page (`index.html`), no build step. Deployed on Vercel from this repo.
Card data and images from Scryfall (https://scryfall.com/docs/api). Unofficial
Fan Content permitted under the Wizards of the Coast Fan Content Policy.
